Elektrik kumanda devrelerini çizip gerçek bir devre gibi çalıştıran özgür eğitim programı. Bahadır Değirmenci ve Alperen Yardım tarafından yapılmıştır.

## Hangi dosyayı indirmeliyim?

| Dosya | Ne zaman |
|---|---|
| `BobinKumanda-{VERSION}-setup-x64.exe` | **Çoğu bilgisayar için bu.** Başlat menüsüne kısayol ekler, `.bobin` dosyalarını ilişkilendirir, Denetim Masası'ndan kaldırılabilir. |
| `BobinKumanda-{VERSION}-setup-x86.exe` | Eski 32 bit Windows 10 bilgisayarlar için. |
| `BobinKumanda-{VERSION}-portable-x64.zip` | Kurulum yapılamayan bilgisayarlar için: zip'i açıp `BobinKumanda.exe`'yi çalıştırın, flaş bellekten de çalışır. |
| `BobinKumanda-{VERSION}-portable-x86.zip` | Taşınabilir, 32 bit. |

Bütün dosyalar **çevrimdışı çalışır**: .NET çalışma ortamı programın içindedir; hedef bilgisayara .NET, SDK ya da internet gerekmez. Dosyayı bir kez indirip flaş bellekle istediğiniz kadar bilgisayara kurabilirsiniz.

Yönetici hesabı yoksa kurulumun ilk ekranında **Yalnızca benim için kur**'u seçin. Program imzasız olduğu için Windows ilk açılışta "Windows bilgisayarınızı korudu" uyarısı verebilir: **Ek bilgi → Yine de çalıştır**. Dosyaların SHA-256 özetleri `SHA256SUMS.txt` içindedir.

Gereksinim: Windows 10 (1607 ve üstü) ya da Windows 11.

**English:** free software for drawing and simulating electrical control circuits. Most PCs need `setup-x64.exe`; use `x86` for old 32-bit Windows and the `portable` zip where nothing can be installed. Every package works offline with the .NET runtime built in.
